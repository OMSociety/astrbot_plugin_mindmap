# 思维导图 / 时间线绘制（astrbot_plugin_mindmap）

插件提供工具 `draw_mindmap(outline, layout, send)`，把 Markdown 大纲渲染成 PNG 图片。

## 何时画、画哪种

| 场景 | layout |
|---|---|
| 知识结构梳理、概念体系、分类对比 | `tree`（思维导图，根在左向右展开） |
| 历史脉络、发展线索、事件先后 | `timeline`（竖轴，节点左右交替） |
| 不确定 | `auto`（按叶子节点是否多为日期自动判定） |

**优先显式传 `tree` 或 `timeline`**；`auto` 只是兜底，判定结果会在返回短语里注明。

## 大纲格式

两种等价写法（可混用），用 `#` 标题或 `-` 列表缩进表示层级：

```markdown
# 主题
## 分支一
- 要点甲
  - 细节
## 分支二
- 要点乙
```

或：

```markdown
主题
- 分支一
  - 要点甲
- 分支二
  - 要点乙
```

时间线节点写成「时间标签: 描述」，标签可省略（按序排列）：

```markdown
# 法国大革命至巴黎公社的思想脉络
- 1789: 三级会议召开，旧制度合法性崩塌
- 1789–1791: 《人权与公民权宣言》颁布
- 空想社会主义思潮兴起
```

## 规模建议与硬上限

软建议（超出后图仍可生成，但返回短语会报节点数，宜主动精简）：

- 层级 ≤ 4 层
- 每个分支 ≤ 6 个子节点
- 总节点 ≤ 60
- 单节点 ≤ 40 字（一句话说清一个要点）

硬上限（超限拒绝生成，会收到固定短语提示）：

- 总节点 > 200，或
- 单节点 > 200 字，或
- 层级 > 8

超限处理：合并同类节点、把长节点拆成父子两级、或拆成多张图分别绘制。**不要静默裁剪内容**。

## 发送纪律（QQ 平台必读）

图片必须由 `draw_mindmap` 本工具发送（`send=True` 默认行为），**不要**改用其他发送类工具（如 `send_message_to_user`）转发达张图。那些工具走主动消息通道，QQ 官方机器人默认无主动发消息权限，会直接被拒（报「主动消息失败，无权限」）。本工具把图片挂在当前用户消息的被动回复上发送，不受此限。

## 调用示例

直接发图给用户：

```
draw_mindmap(outline="# 康德的批判哲学体系\n## 纯粹理性批判\n- 先验感性论\n- 先验逻辑", layout="tree", send=True)
```

嵌入 docx 等文档（不发图，只取文件路径）：

```
draw_mindmap(outline=..., layout="tree", send=False)
```

返回值：发图场景是一句可直接转发的短确认（如「已发送思维导图（21 个节点）。」），原样转给用户即可；`send=False` 时只返回文件路径，用文件工具读取该路径即可嵌入 docx 或做二次加工，**不要把路径念给用户**。

## 学术准确性要求

- 节点文字必须忠于原始材料，不臆造、不静默删改；超长内容拆节点而非截断。
- 时间线的时间标签须与史料一致，不确定的年份标注「约」。
- 大纲结构应反映学界公认的分类框架；有争议处按用户给定的口径组织。

## 回复纪律（重要）

- 用户表达画图意图后直接调用工具，**不要先复述大纲、不要预告流程、不要画前确认**（用户明确要求先看大纲除外）。
- 发图后至多一句短确认（工具返回什么就转什么），**不要再把图的内容用文字解释一遍**。
- 图片已承载全部信息，文字只用于必要的状态说明（失败/超限）。

## 常见失败短语与对策

| 短语 | 对策 |
|---|---|
| 大纲为空 | 传入非空大纲文本 |
| 第 N 行：列表缩进 N 个空格不是 2 的倍数 | 把该行缩进改成偶数空格（2/4/6…）或改用 tab |
| timeline 布局仅支持一层事件节点 | 改用 tree 布局，或把深层条目并入父节点描述 |
| 节点数/单节点字数超上限 | 按上文规模建议精简后重试 |
